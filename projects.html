PROJECT METADATA: SPEECH TO SIGN LANGUAGE TRANSLATION


🎮 Objective:
Developed a web application that converts speech and text into sign language animations using the Django framework. Integrated the Web Speech API to capture voice input and convert it into text in real time. Processed the input by extracting keywords and mapping them to corresponding sign language video animations. Implemented sequential video playback with a responsive user interface to provide an interactive and accessible user experience.


🛠️ Tech Stack Built With: Python, Django, HTML, CSS, JavaScript, Web Speech AP
